# 请求侧字段映射表 (AddData 反汇编, 2026-08-26)

> 来源: 69 个 ApiManager 请求方法 + lambda 反汇编 (extract_request_fields.py)
> 原始数据: request_fields.json — 每端点实际发送的表单字段 (权威)

## 认证
- HTTP 头: `TOKEN` (AddHeader) + `UUID` (login1st)
- 表单: token (login 系)

## 已确认的关键字段 (与私服原实现差异!)

| 端点 | 客户端实际发送 | 私服原实现 ❌ |
|---|---|---|
| livestage/finishgame | `total_score`, `max_combo`, `full_combo`, `hit_ranks_counts`, `play_log`, `unit_id`, `friend_id` | score, stage_id |
| livestage/playgame | `stage_id`, `movie_id`, `effect`, `event/exp/coin/drop/friendly_bonus_item_num` | stage_id ✓ |
| shop/buy | `pack_id` | shop_item_pack_id ❌ |
| deck/leader | `deck_id` + `pos` | deck_id + card_id ❌ |
| deck/card | `card_id` + `pos` | deck_pos ❌ |
| acce/lock | `acce_id` | card_id ❌ |
| card/grow | `card_id[]` (材料数组, 目标=当前卡上下文) | card_id + material_card_ids |
| profile/favorite_card | `card_id` ✓ | ✓ |
| account/handover | `handover_player_id` + `handover_code` ✓ | ✓ |
